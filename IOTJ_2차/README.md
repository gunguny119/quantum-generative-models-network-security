# IOTJ 2차 — contextuality 노브에서 양자/고전 학습격차 임계곡선 (마스터 로그)

> **한 줄 주제**: 데이터의 contextual fraction(CF)을 연속 조절하면, 메모리매칭 양자/고전 생성모델의 학습격차 gap 이
> **gap ≈ c·CF²** 로 켜지는가 — 그리고 이 법칙이 **실측 양자 데이터**에서도 성립하는가.
> ★ 모든 "우위" = **메모리매칭 모델클래스 분리**이지 **quantum supremacy 아님**. 소규모(2,2,2)/KCBS·시뮬 한정. 단정 금지.

- 작업 디렉터리: `IOTJ_2차/`. 결정적(seed 고정), 무설치(numpy·scipy). 각 실험은 앞 실험을 **무수정 import 재사용**.
- 개별 상세 로그: `docs/agent_logs/*.md` (아래 표의 각 행). 코드: `tools/*.py`. 산출: `results2/<실험>/`.

## 종합 서사 (지금까지)
1. **(1)** contextuality 를 연속으로 켜면, 메모리매칭 양자-고전 학습격차 gap 이 **CF>0 되는 순간** 켜진다(스위치). 원인은 메모리가 아니라 **비맥락 폴리토프를 양자가 넘어서는 접근성**(P4 인과 확정).
2. **(2)(3)** 그 gap 은 CF 에 **볼록**하며, 정보기하로 **gap ≈ ½χ²·CF²** (c = 교차 facet 의 χ² 곡률, 방향의존; 균등방향 1/6·1/8). 경계정착 방향에선 선형(α=1)로 무너짐 — 법칙의 성립 조건도 규명.
3. **(4)(5)(6)** 이 법칙이 **실측 데이터로 곡선 양 끝에서 정박**:
   - **켜진 앵커**: KCBS 이온(CF0.263)·Delft 다이아몬드 Bell(CF0.211) 두 양자 플랫폼이 곡선 위(3.7%, 5.3%), KCBS KL_q 실측=0 확정.
   - **꺼진 앵커**: 실 IoT 텔레메트리(N-BaIoT 3기기) CF≈0 실측 → gap 상한 ≤2.9e-9(곡선 원점 근방). NIST·보안데이터도 작은-CF/gap≈0.
4. **연결(1차→2차)**: 1차 결론 "실 보안데이터 CF≈0 → 양자 무우위"의 **대우 "CF>0→gap>0"** 를 통제노브+실측앵커로 세움. 우리 malware/traffic 데이터엔 자원(CF)이 없어(gate1 CF≈0) 무우위였고, CF>0 인 곳(양자물리)에선 법칙대로 gap 이 켜짐.

## 공통 한계 (모든 실험 적용)
- **(2,2,2)/KCBS 소규모·시뮬레이션·메모리매칭 정의 의존·finite-sample**. CF-LP 는 상한/근사. NCfloor 수치최소화.
- **PR box 는 초양자(비물리)**; 양자실현은 CF≤√2−1(Tsirelson)까지. **관측/유도 법칙이지 supremacy 아님**(모델클래스 분리).
- 실데이터: KCBS=4-cycle(오각별 아님)·상관재구성; Delft n=245 소규모·no-signalling 잔차 0.089; NIST=시행 재구성 불가(정성).

## 다음 후보 (열린 것)
1. **선형 레짐 실측 앵커**: 경계정착 방향(α=1) 데이터점을 실측으로도 확인.
2. **Delft no-sig 잔차 처리**: 무신호 사영 후 CF·gap 재측정(잔차 영향 격리).
3. **c 의 해석식**: 균등방향 1/6·1/8 유리수의 닫힌형 유도.
4. **더 큰 시나리오**: n>5 cycle·다중큐빗으로 법칙 일반성·supremacy 경계 탐색.
