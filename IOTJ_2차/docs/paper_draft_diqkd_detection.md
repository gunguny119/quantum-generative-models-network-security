# 논문 서술 초안 — contextuality 학습격차 법칙과 그 탐지-경계 (DI-QKD 확장)

> **상태**: 초안(2026-07-24). 층위 1은 기존 결과, 층위 2·3은 신규(gate_s1/s2/s2b/s2c).
> **프레이밍 철칙**(본 초안 전체 준수):
> 1. **"양자 탐지 우위" 주장 금지.** 본 실험이 그것을 반증했다. 우위는 "모델기반 vs S-검정"이지 "양자 vs 고전"이 아니다.
> 2. **키 보안 개선 아님.** 서술은 **장비 무결성/변조 모니터링**, **S-검정 보완 계층**으로 한정.
> 3. **CE 방법론 발견**(탐지엔 deviance 를 써야 함)은 별도 소절로 서술.
> 4. **Abstract 재정의**: "탐지 우위"가 아니라 **"탐지 가능성의 경계를 c·CF²로 규정"**.
> 5. ★모든 곳: 모델클래스 분리이지 **quantum supremacy 아님**. (2,2,2)·소규모·시뮬 한정. 단정 금지.

## 제안 제목(후보)
- "Contextual fraction sets both the learning gap and its detectability boundary in (2,2,2) scenarios"
- "From gap ≈ c·CF² to a detectability shell: what a device-fingerprint monitor can and cannot see"

## Abstract (초안 — 재정의판)
데이터의 contextual fraction(CF)을 연속 노브로 조절하면 메모리매칭 양자/고전 생성모델의 학습격차가 **gap ≈ c·CF²** 로 켜진다(층위 1, 기존; 실측 양자 앵커 KCBS·Delft 로 정박). 본 연구는 이 분포-수준 법칙이 **탐지(변조 모니터링) 수준에서 무엇을 함의하는가**를 규명한다. 핵심 결과는 **우위가 아니라 경계**다: (i) 정상 장비에 적합된 생성모델 템플릿은 **CHSH S-검정이 완전히 놓치는 S-보존 변조**를 AUC≈1 로 포착하여 S-검정과 **상보적**이나(장비 무결성 계층), (ii) 이 이점은 **양자 특유가 아니며**(고전 비맥락 템플릿도 동급), (iii) **강한 불가능성 정리**로 그 이유가 규정된다 — 정상 상자는 고전탐지기의 blind 공 {KL(‖고전템플릿)≤NCfloor} 안에서 CHSH-S 를 **유일 최대화**하므로, 무신호 폴리토프 전체(양자∪초양자, PR-box 포함)에서 "고전엔 안 걸리고 양자엔 걸리는" 변조는 **존재하지 않는다.** 이 blind 공의 반지름이 정확히 **NCfloor = c·CF²** 로, 분포-수준 법칙(층위 1)과 탐지-수준 경계(층위 2)가 한 양으로 이어진다(층위 3). 방법론적으로, 자연스러운 음의 로그우도(NLL) 스코어는 표본 엔트로피에 교란되어 부적합하며 **deviance(2N·KL~χ²)** 를 써야 함을 함께 보인다. ★모델클래스 분리이지 supremacy 아님; 소규모(2,2,2)·시뮬레이션·유한표본 한정.

## 층위 1 — 분포 수준: gap = c·CF² (기존, 유지)
- 노브 e(λ)=λ·PR+(1−λ)·균등에서 gap 은 CF>0 되는 순간 켜짐(스위치), 원인=contextuality(P4 인과대조).
- 정보기하 유도 **gap ≈ ½χ²·CF²**, 균등방향 c=1/6(CHSH)·1/8(KCBS).
- 실측 양자 앵커: KCBS 이온(CF=0.263, 3.7%)·Delft 다이아몬드 Bell(CF=0.211, 5.3%) 곡선 위. 꺼진 앵커: 실 IoT(N-BaIoT) CF≈0.
- (본 초안은 이 층위를 **전제**로 인용; 세부는 기존 gate_r1/r2/r3/e_coefficient 로그.)

## 층위 2 — 탐지 수준: 상보성 + 경계(신규)

### 2.0 설정 (gate_s1: 시뮬레이터·재현)
- DI-QKD (2,2,2)=CHSH. 모든 공격을 16셀 behavior 로 환원 → 기존 build_box 로 (a,b,x,y). 시뮬레이터가 Delft Hensen2015 실측(V=0.856→S=2.42, n=245)을 1000 reps 로 CF/gap/S 밴드 재현(STOP 게이트 PASS). 정상 운용점: V=0.856, CF≈0.211.
- 탐지기: 정상 데이터에 적합된 **고정 템플릿 대조**(재적합 아님)=장비지문. 양자 템플릿 q_model, 고전 비맥락 템플릿 c_model(NCfloor 도달점), S-검정.

### 2.1 방법론 발견 — 스코어는 deviance 여야 함 (gate_s2, 별도 소절)
- **자연스러운 NLL(=CE=−Σemp·log model)은 부적합**: CE=H(emp)+KL 로 **표본 엔트로피에 교란**. 비맥락 공격(mimic_ncfloor, CF=0,S=2)은 정상보다 엔트로피 높아, NLL 로는 양자·고전·S-검정 세 탐지기가 **동률**(AUC 0.99, Δ≈0) — 우위처럼 보이는 것이 실은 엔트로피 신호.
- **교정: deviance/G-통계량** KL(emp‖model)=CE−H(emp), **2N·KL ~ χ²**(포화모델 대비 우도비). 경험박스만으로 계산 가능. 이걸 쓰면 모델불일치가 격리됨.
- deviance 로 보면 **gap→탐지마진 단조**: CF 0→0.41 스윕에서 ΔAUC 0→1, **Spearman=1.000**(함수형 c·CF² 주장은 하지 않음; 단조성만).
- ※ 단, mimic 은 S=2(고전적)라 S-검정 자체를 통과 못 함 → "S-검정보다 정밀한가" 격리 불가 → 2.2 로 승계.

### 2.2 상보성 — 모델 템플릿 ⊥ S-검정 (gate_s2b, **주 양성 결과**)
S-검정을 통과(S≈2.42)하는 변조를 quantum_behavior(p) 이미지(물리 구현 가능)에서 탐색. deviance 스코어, N_train=10⁴.

| 공격 (S) | 양자 템플릿 | 고전 NC 템플릿 | S-검정 (N=245/1000) |
|---|---|---|---|
| **iso_S** (2.42) | **1.00** | **1.00** | 0.53 / 0.57 |
| **marginal_matched** (2.42) | **1.00** | **1.00** | 0.50 / 0.59 |
| partial_05 (2.35) | 0.46/0.45 | 0.42/0.29 | **0.58/0.72** |
| partial_10 (2.27) | 0.49/0.60 | 0.34/0.17 | **0.75/0.89** |
| partial_20 (2.12) | 0.53/0.74 | 0.30/0.08 | **0.83/0.98** |

- **(양성) S-보존 지문변조**: 모델 템플릿 AUC=1.0, **S-검정 완전 blind(≈0.5)**. marginal_matched 는 marginal 일치(QBER 모니터 우회)에도 잡힘.
  → **생성모델 장비지문 모니터가 CHSH S-검정의 사각지대(S-보존 변조)를 포착. S-검정 보완 계층(장비 무결성).**
- **(상보) S-저하 공격**(partial=intercept 소량혼합): **S-검정이 잡음**(0.58→0.98), 모델 KL 은 ≤0.5(intercept 가 데이터를 더 '고전적'으로 만들어 고전템플릿엔 덜 이상 → AUC<0.5).
  → **두 계층이 disjoint 공격을 커버 = defense-in-depth.**
- **(정직한 경계) 이 우위는 양자 특유 아님**: 양자 템플릿과 고전 NC 템플릿이 (a)에서 동급(둘 다 1.0).

### 2.3 강한 불가능성 정리 — 왜 양자 특유가 아닌가 (gate_s2b·s2c, **구조 정리**)
- **정리**: S=S_normal 인 **모든 무신호 상자**(양자∪초양자, PR-box 포함) 중 정상이 고전템플릿 거리 KL(‖c_model)=NCfloor 를 **유일 최소화**. 동치로, 정상은 고전탐지기 **blind 공** {KL(‖c_model)≤NCfloor} 안에서 CHSH-S 를 **유일 최대화**.
- **따라서** (고전 blind) ∧ (S≥S_normal ⇒ S-검정 blind) ∧ (≠정상) 은 **무신호 폴리토프 전체에서 동시 불가.** 즉 "고전엔 안 걸리고 양자엔 걸리는" 변조(blind_shell)는 **초양자(비물리 PR-box) 공격자에게조차 부재.**
- **검증**: (i) quantum_behavior(p) 최적화 → 정상 붕괴(KL→normal≈1e-4). (ii) 무신호 4-상관 전수 그리드(≈2만 상자) → MIN KL→c = NCfloor(정상), 껍질 위 정상과 먼 상자 0개. TLM(Tsirelson–Landau–Masanes) 판정으로 양자/초양자 분류.
- **함의**: 양자 템플릿의 **고유 탐지역 = 공집합.** 모델기반 모니터의 값(2.2 양성)은 전적으로 **비양자적**(고전 NC 템플릿과 동급). → **우위 정리가 아니라 탐지가능성 경계 정리.**

## 층위 3 — 연결: 탐지 껍질 반지름 = NCfloor = c·CF²
- 고전탐지기의 blind 공 반지름(=정상이 그 위에서 S 최대인 껍질)이 **NCfloor**. 정상 운용점에서 **NCfloor = 0.00778 ≈ c·CF² = 0.00739**(c=1/6, CF=0.211).
- 즉 **분포-수준 법칙(gap≈c·CF²)의 그 c·CF² 가, 탐지-수준에서 "무엇이 숨을 수 있는가"의 반지름을 규정.** 한 양이 두 층위를 잇는다: 학습격차의 크기 = 고전탐지기 blind 공의 크기.

## 한계 (필수, 본문·별도절)
- (2,2,2) 소규모·시뮬·메모리매칭·유한표본. 균등 marginal·4-상관 무신호 한정(비균등 별도).
- iso_S/marginal_matched 는 특정 정상 운용점의 존재증명(모든 공격 커버 아님). 초양자 상자는 비물리(worst-case 가정 공격자).

- **모델클래스 분리이지 quantum supremacy 아님. 키보안 개선 아닌 장비무결성/변조모니터링 맥락.**

## 기여 요약 (한 문단)
분포-수준 법칙 gap≈c·CF² 를 **탐지-수준으로 확장**하여, (1) 생성모델 장비지문이 S-검정과 **상보적**으로 S-보존 변조를 잡음을 보이고(장비 무결성 계층), (2) 이 이점이 **양자 특유가 아님**을 **강한 불가능성 정리**(무신호 전체에서 blind_shell 공집합)로 규정하며, (3) 그 경계의 반지름이 정확히 **c·CF²(=NCfloor)** 임을 밝혀 두 층위를 잇는다. 아울러 탐지 스코어로 **deviance(2N·KL~χ²)** 가 필요함을 방법론적으로 확립한다. — 우위가 아니라 **가능성의 경계**를 규정하는 결과.
