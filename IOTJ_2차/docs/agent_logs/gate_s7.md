## [측정된 사실]

1. 저장된 `detection_strongest`(0.9949/0.517/0.4825)를 **비트 단위로 재현**했다.
2. 유한표본 적합 템플릿에서도 양자-고전 분리가 유지된다. **N\* = 980으로 두 계열이 같다.**
3. S-검정은 전 N에서 0.47~0.51 — 완전 blind.
4. Delft 실측 시행수 N=245에서 양자 AUC는 **0.657** — 탐지 실패. N\*는 그 **4배**다.
5. 스윕 2회 재실행 결과 JSON이 동일하다(결정성 확인).

## [탐색의 한계]

- 공격점은 `exact_slsqp` 국소 최적해 **1점**. 전역 최대 보장 없음.
- N\*는 격자상 값이며 보간하지 않았다. 실제 임계점은 490~980 사이.
- `reps=100`, 훈련시드 10벌. AUC 자체의 몬테카를로 오차는 별도 정량화하지 않았다.
- **3-3(N\*(KL) 역스케일링)은 미수행** — Phase 1의 공격점 족이 필요하다. 저장된 `delta_sweep` 점들은 KL이 0.0098~0.0102로 4% 범위라 관계식을 낼 수 없다.
- 환경이 numpy 2.2.6 / scipy 1.15.3이다. ~~모집단 NCfloor 재계산 시 저장값 대비 2.4e-12 편차~~ → **정정(2026-07-28)**: 이 편차의 원인은 환경이 아니라 **`fastq` 미설치**였다. `fastq.install_23` 적용 후 NCfloor는 `0.0060078850653856632`로 저장값과 **차이 0.00e+00**. 저장 결과는 fastq 설치 상태에서 생성됐으며 재현은 완전하다. 단 fastq 없이 실행하면 ~1e-16 차이가 Powell을 거쳐 ~2.4e-12로 증폭되므로, **재현 시 fastq 설치는 필수**다.

## [미검증·추정]

- 고전 AUC ≈ 0.5는 공격점이 등식제약으로 고전 껍질 위에 놓이도록 **구성된** 결과다. **발견이 아니다.** 논문에서 이를 "고전 탐지기가 실패했다"는 발견으로 쓰면 과장이다. 발견은 **양자 템플릿이 유한표본에서도 신호를 유지한다**는 쪽이다.
- 유한표본 고전 템플릿이 큰 N에서 0.545까지 오르는 것은 적합 잡음이 등거리성을 깨기 때문으로 보이나, 검정하지 않았다.
- ★R6 준수: (2,2,2) 커버리지 불가능성 정리와 무모순. 장비 무결성 맥락이지 키 보안 아님. 모델클래스 분리이지 supremacy 아님.
