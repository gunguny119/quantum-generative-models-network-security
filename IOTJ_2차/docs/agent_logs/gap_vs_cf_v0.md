## ★ "우위"의 정의 (모든 산출물에 명기)
여기서 **gap 은 메모리(파라미터) 매칭된 모델클래스 분리**이지 **quantum supremacy 가 아님**.
- 고전 사다리 = no-signalling **국소(=비맥락) 은닉변수 잠재모델**(Fine 정리로 국소 폴리토프에 갇힘) + 암기용 CPT(참조).
- 양자 = 2큐빗 empirical model(양자 집합 ⊋ 국소집합, 단 **Tsirelson 한계**로 초양자 PR 은 실현 불가).
- **PR box 는 초양자(비물리)** — λ_Q=1/√2 위 영역은 양자로도 실현 불가. 관측 법칙이지 supremacy 주장 아님.

## 노브·과제·모델
- **e(λ) = λ·e_SC + (1−λ)·e_NC**, e_SC=PR-box(2,2,2), e_NC=균등잡음(비맥락). 이론 CF(λ)=max(0, 2λ−1).
- 과제(순차/스트리밍, 스텝 독립): 컨텍스트 c_t~unif{(x,y)} → 모델이 outcome (a,b) 분포 출력. 타깃=e(λ) 조건분포.
  N∈{∞(모집단),5000}, 평가=held-out 컨텍스트별 KL(타깃‖모델) 평균, seed 5.
- 모델(파라미터): 양자 2큐빗 **9** ; 고전 잠재 H∈{1(독립)=4, 2=9, 3=14, 4=19, 6=29, 8=39} ; CPT(암기)=12.
- **gap_matched** = KL_class(±20% 파라미터=H2) − KL_quantum  (명세 letter; 표현력 교란 포함).
- **gap_contextual** = KL_best-NC(무제한메모리 국소폴리토프 하한) − KL_quantum  (**주지표**: CF=0 이면 0 → 순수 contextuality 분리).

## 판정 P1~P5
- **P1 임계 존재**: gap_contextual 이 0→양수로 처음 넘는 **λ_emp = 0.55** (CI[0.55,0.55], N=∞ 결정적; 첫 CF>0 점 0.525에서 이미 +0.0004,
  탐지역치 1e-3 기준 0.55). 부트스트랩 무임계 확률 0%. (참고: gap_matched 는 λ_emp=0.10 — 표현력 교란으로 CF=0에서도 양수.)
- **P2 임계 위치**: λ_emp(주지표) ≈ **0.55 ≈ λ*=0.5** (CF>0 경계). → **"CF가 학습격차의 스위치" 첫 실증**.
  gap_contextual 은 CF=0 전 구간(λ≤0.5)에서 정확히 0, CF>0 되는 순간 켜짐. dead zone(지연) 아님.
  ※ 단, 이는 **주지표(비맥락 폴리토프 기준)** 판정. 동일-파라미터 gap_matched 는 표현력 차이로 더 일찍 켜짐 → 순수 스위치는 주지표로만 주장.
- **P3 곡선형태**: CF>0 영역 회귀 — **구간선형(문턱/볼록) 승** (AIC: piecewise **−94.5** < sigmoid −85.5 < **linear −77.9**).
  선형기울기 0.14, 꺾임 CF≈0.25. → **ABM 소비 선형법칙과 비동형**: 학습-KL gap 은 CF 에 **볼록(초선형)**. (KL 기하가 폴리토프 경계 근방 2차 → 자연스러운 볼록성.)
- **P4 인과대조**(e_SC→CF=0 완전상관 비맥락상자): 전 λ에서 **gap_contextual ≤ 3e-5 ≈ 0 (소멸)**.
  → **상관이 아니라 contextuality 가 원인** 확정. (완전상관은 H2 공유은닉비트로 정확 재현 → 고전 하한 0.)
- **P5 실데이터 앵커**(재학습 없이 CF 축 위치만): **KCBS CF=0.263**(실측, 양자실현영역 CF<0.414 & gap>0 영역 → 학습격차 존재 예측),
  **보안데이터(Tinba IAT) CF≈4.5e-5**(≈0 경계 → gap 없음=dead). 곡선 위 배치는 `gap_cf.png` 좌측 삼각형 마커.

## 유한표본(N=5000) — 강건성
gap_contextual 이 N=∞ 와 거의 동일(예 λ=0.8: +0.0632±0.0002 vs ∞ +0.0629), seed σ~2e-4. **CF=0 에서 유한표본이 가짜 gap 을 만들지 않음**(λ=0.5: −0.0000±0.0001). KL_quantum 은 유한표본 바닥 ~7e-4(∞에선 0) = finite-sample 효과.

## 보조노브 — Tsirelson(양자실현) 영역 구분
등방혼합선에서 양자실현 한계 **λ_Q=1/√2≈0.707**, 그 CF=**√2−1≈0.414**. 실측 KL_quantum: λ≤0.707 에서 ≈0(정확 실현), λ>0.707 부터 상승(초양자→근사만). 그림에 음영 구분.
- ⚠ **명세의 "CF_max≈0.207" 은 본 등방혼합 계산과 불일치**(√2−1≈0.414). self-check 로 그대로 보고 — 0.207 은 다른 정규화/시나리오 값으로 추정되나 미확인. **단정 않고 계산값 0.414 사용**.
