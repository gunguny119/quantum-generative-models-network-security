## CF=0.207 문제 해결 (명세 오류 규명)
명세 초기 `CF_Tsirelson≈0.207` 은 **오류**였음. 등방혼합선에서 양자실현 한계는 CHSH=2√2 이고
**CF = (CHSH−2)/(4−2) = (2√2−2)/2 = √2−1 ≈ 0.4142**. 0.207 은 정확히 그 **절반** → 분모를 (4−2)=2 대신
(4−0)=4 로(또는 2배) 정규화한 실수로 추정. 본 실험 전 구간 **0.4142 사용·검증**(Gate A 이륙점·Gate D 로 교차확인).

## gap 분해와 4가설
gap(CF) = **NCfloor(CF)** − **KL_quantum(CF)**.  (NCfloor=무제한메모리 국소=비맥락 폴리토프 하한)
- **H1 기하**: 경계 CF→0+ 에서 NCfloor~CF² (KL≈½χ² 기하), 국소지수 α→2.
- **H2 Tsirelson**: KL_quantum 이 CF≈0.414 에서 0→양수 이륙.
- **H3 방향**: gap 이 CF 만의 함수인가(혼합방향 바꿔 CF축 붕괴?).
- **H4 아티팩트**: v0 "꺾임 CF≈0.25" 가 매끄러운 볼록곡선에 구간선형을 억지적합한 산물인가.

## Gate A — 성분분해·국소지수·이륙점·적합족 (λ 0.5~1.0, 0.01 간격, 51점)
**1) 볼록성은 NCfloor 에 산다.** KL_quantum 은 CF≤0.414 에서 정확히 0(평탄) → 그 구간 gap=NCfloor. 볼록곡률은 전적으로 NCfloor.

**2) 국소지수 α(CF) = d log NCfloor / d log CF** (수치미분, 창2·창4 일치):
| 구간 | α (창2 중앙값) | 해석 |
|---|---|---|
| 경계 CF≲0.4 | **≈2.0** (2.01–2.2) | **NCfloor ~ CF² 기하법칙** |
| CF→1 (PR극점) | 2.5→3.7 상승 | 폴리토프 먼 영역 곡률 증가 |
→ 경계 멱법칙 적합 **α=2.04** (a=0.188). **H1 성립.**

**3) KL_quantum 이륙점 = CF 0.440 ≈ Tsirelson 0.414** (그리드 0.02·역치 1e-4 오차). **꺾임(0.25) 아님. H2 성립.**

**4) 적합족 AIC** (y=gap, x=CF>0; 낮을수록 우수):
| 모형 | AIC(전체) | AIC(경계 CF≤0.414) |
|---|---|---|
| **quad_to_linear** | **−907.8** ★ | −357.7 |
| **quadratic** | −586.8 | **−373.2** ★ |
| piecewise_linear | −710.4 | −289.6 |
| linear | −509.3 | −238.0 |
| power_law (α≈1.95) | −469.7 | −333.3 |
- 전체 최적 = **2차→선형 크로스오버**, **크로스오버 노드 CF=0.428 ≈ Tsirelson 0.414**.
- 경계(CF≤0.414) 최적 = **2차**. 두 경우 모두 **구간선형을 이김**.
→ **H4 성립: v0 '꺾임 CF≈0.25'는 아티팩트.** 실제 구조는 (i) 경계에서 매끄러운 **CF² 2차곡선**, (ii) **Tsirelson(0.43)에서 준선형으로 크로스오버**(양자바닥 KLq 점등이 gap 곡률을 완화). v0 의 구간선형은 이 매끄러운 2차에 억지로 꺾은선을 맞춰 노드를 0.25~0.31 로 오배치.

## Gate B — 방향 스윕 (H3): **비붕괴 (독립 발견)**
PR-box 를 4방향과 혼합 후 각자 CF축 위에 NCfloor 중첩:
| 방향 | CF≈0.5 에서 NCfloor |
|---|---|
| 균등잡음(기존) | 0.048 |
| 결정론 꼭짓점 (0000) | 0.109 |
| 결정론 꼭짓점 (0101) | 0.068 |
| 국소 완전상관 | 0.101 |
- **방향간 최대 상대편차 = 1.79 → 붕괴 안 함(collapse=False).** 같은 CF 라도 NCfloor 가 방향에 따라 **~2배** 차이.
- → **CF 는 gap 의 충분통계가 아니다. 폴리토프에서 떠나는 기하 방향이 gap 을 좌우.** (지수 α=2 는 보편, 계수 c 는 방향의존.)
  독립 발견으로 보고: **gap ≈ c(방향)·CF²**, α=2 는 보편·c 는 기하.

## Gate C — KCBS 5-cycle 일반성: **CF² 시나리오-보편**
KCBS 극점(홀수 사이클 반상관)↔균등 노브. cyclic CF-LP·NCfloor 신규 구현(gate1 정신 계승).
- KCBS 경계 국소지수 **α = 2.26 ≈ CHSH α = 2.20**. NCfloor(CF) 곡선도 CHSH 와 거의 중첩(그림 우하).
→ **CF² 기하법칙은 (2,2,2) CHSH 에 국한되지 않고 5-cycle 로 일반화.** H1 의 시나리오-보편성 확인.

## Gate D — 양자 용량 불변 (H4-양자 배제): **불변**
양자 파라미터 {6(평면), 9(기본), 14(일반상태)}:
| 용량 | 이륙점 CF | CF<0.414 최대 KLq |
|---|---|---|
| q6 | 0.50 | 9.8e-15 |
| q9 | 0.50 | 1.8e-13 |
| q14 | 0.50 | 2.5e-12 |
- **세 용량 모두 이륙점 동일**(0.50, Gate D 격자 0.05 한계값), **CF<0.414 에서 KLq≈0(≤1e-12)**.
→ **이륙점·바닥이 양자 용량에 불변** = 꺾임/크로스오버는 양자 표현력 아티팩트 아님(Tsirelson 이 물리한계이기 때문).
- ※ 자동 플래그 `invariant=False` 는 격자한계 이륙값 0.50 이 0.414±0.06 밖이라 뜬 것(임계 판정 보수적). **세 용량 값이 서로 동일**하고 CF<0.414 KLq≈0 이므로 **불변 결론은 견고**(격자·역치 산물, 물리 아님).

## 사전등록 예측 대비
- **H1 예측("경계 CF² 법칙, 계수 c 는 시나리오 기하 의존") 정확히 성립** — α=2 보편(Gate A·C), 계수 c 방향의존(Gate B) 까지 확증.
- 발견 1(v0 "볼록 gap")이 **법칙으로 격상**: *학습 gap ≈ c·CF² (경계), 지수 2 보편, ABM 소비-선형법칙(지수 1)과 지수부터 다름.*
