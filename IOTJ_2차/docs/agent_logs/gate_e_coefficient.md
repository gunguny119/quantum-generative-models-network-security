## 이론 (정보기하 χ² 곡률 → 계수 c)
경계 근방 KL(e‖q) ≈ **½ Σ_i (e_i−q_i)²/q_i** (χ² 2차형). NCfloor(CF)=비맥락 폴리토프까지 KL 거리이므로,
경계에서 e(CF)=q*(CF)+Δ, Δ≈CF·δ →
  **NCfloor ≈ ½ Σ Δ_i²/q_i = CF²·[½ Σ δ_i²/q_i] = c·CF²,  c = ½·(최근접 facet 의 χ² 곡률).**
⇒ 방향별 **c_pred = ½χ²(e_ref, q*) / CF²** (이론) 를 **c_fit**(NCfloor~c·CF² 적합)과 대조. 일치 역치 ≤10%.
보조 **c_direct = NCfloor/CF²**(KL 직접) — c_pred 와 비교 시 χ²≈KL 근사품질 측정.

## 방법
- 각 방향: CF 를 λ 스캔으로 싸게 측정 → 경계점(0<CF≤0.1) 선별 → 각 점서 KL 투영 q*(nc_project, 다중초기값) → Δ=e−q*.
- c_fit = NCfloor~c·CF² 원점통과 최소자승(+R²). α = log-log 기울기(지수 self-check). c_pred = CF→0 극한(최소 CF 3점 평균).
- 시나리오: **CHSH(2,2,2) 4방향** + **KCBS 5-cycle 2방향**. 방향 = PR/KCBS 극점 ↔ {균등·결정론 꼭짓점·국소상관}.

## 판정 — 레짐 분리 (정직 보고)
### ✅ CF² 레짐 (매끄러운 내부-facet 통과): 4/4 방향서 이론 확정
- **c_pred(½χ²) ≈ c_fit ≈ c_direct 전부 ≤2.2%**, α=2.00–2.01. → **gap ≈ ½χ²·CF², c = ½·(facet χ² 곡률)** 은
  **정보기하에서 유도된 법칙**임을 확정(이 레짐서). χ² 2차근사 = 실측 KL 을 <0.5% 로 재현(c_pred vs c_direct).
- **c 는 상수가 아니라 방향의 χ² 곡률에 의존**: 같은 CHSH서 uniform c=0.167 vs det_vertex_0101 c=0.202(≈21% 차).
  → v1 발견 H3("CF 는 충분통계 아님, 방향이 gap 좌우")를 **정량 격상**: 계수 c = 교차 facet 의 χ² 곡률.
- **깨끗한 유리수 관측**: 균등방향 c_pred = **1/6(CHSH), 1/8(KCBS)** 정확 → χ² 곡률의 닫힌형 존재 시사(수치값, 해석식 미유도).

### ⚠ 선형 레짐 (경계정착 방향): 법칙 수정 — gap ∝ CF¹
- det_vertex_0000·local_perfect_corr: 비맥락 기준상자가 폴리토프 **경계(꼭짓점/모서리)에 정착** → 혼합 즉시 맥락적(λ₀≈0),
  KL 투영 q* 가 **e>0 셀에서 support 0** → χ² = Σ Δ²/q **발산**. 경계지수 **α=1.00(선형)**, c·CF² 적합 R²≈0.79(부적합).
- → **χ² 2차예측의 전제(내부 facet)가 위배되는 방향에선 CF² 법칙이 성립하지 않고 gap ∝ CF¹**. 은폐 없이 보고.
- 판별식: **α≈2 ⇔ q* 가 e-support 를 덮는 매끄러운 facet 통과(CF² 법칙·χ² 유효)** vs **α≈1 ⇔ 기준상자가 경계 꼭짓점(선형·χ² 무효)**.
