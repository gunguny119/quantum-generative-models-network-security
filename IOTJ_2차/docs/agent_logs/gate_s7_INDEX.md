## Phase A — Δ(τ, N) (파생, 신규 실행 0회)

`s7_phase1.json → phase1C.rows[].sweep[]` 에 이미 (τ, N) 별 quantum/classical/S_test 중앙값과 훈련시드 10벌 원시 배열이 저장돼 있었다. **재측정은 불필요했다.**

> 프롬프트가 가정한 *"Phase 1 은 고전이 0.5 를 벗어나는 지점만 봤고 양자와 고전을 나란히 재지 않았다"* 는 **사실과 다르다.** 나란히 재서 저장했고, 요약 표에 `|c−0.5|max` 만 실었을 뿐이다.

**Δ(τ,N) = AUC_q − AUC_c**

| τ | N=245 | N=490 | N=980 | N=1960 | N=4900 | N=24500 |
|---|---|---|---|---|---|---|
| 0 | 0.1586 | 0.2681 | **0.4149** | **0.4628** | **0.5010** | **0.4552** |
| 1e-4 | 0.1600 | 0.2703 | 0.4119 | 0.4567 | 0.4852 | 0.4150 |
| 3e-4 | 0.1686 | 0.2744 | 0.4072 | 0.4413 | 0.4538 | 0.3409 |
| 1e-3 | 0.1696 | 0.2804 | 0.3810 | 0.3850 | 0.3545 | 0.1411 |
| 3e-3 | 0.1766 | **0.2804** | 0.3160 | 0.2446 | 0.1351 | 0.0034 |
| 1e-2 | **0.1786** | 0.2050 | 0.1067 | 0.0299 | 0.0006 | 0.0000 |
| 3e-2 | 0.1047 | 0.0376 | 0.0010 | 0 | 0 | 0 |
| 1e-1 | 0.0009 | 0 | 0 | 0 | 0 | 0 |
| 0.353 | 0 | 0 | 0 | 0 | 0 | 0 |

### τ\* (Δ 최대 지점) 과 τ_conv (우위 소멸선)

| N_eval | τ\* | Δ(τ\*) | q / c | τ_conv |
|---|---|---|---|---|
| 245 | **1e-2** | 0.1786 | 0.842 / 0.663 | 0.1 |
| 490 | **3e-3** | 0.2804 | 0.861 / 0.581 | 0.03 |
| 980 | **0** | 0.4149 | 0.921 / 0.507 | 0.03 |
| 1960 | **0** | 0.4628 | 0.993 / 0.531 | 0.01 |
| 4900 | **0** | 0.5010 | 1.000 / 0.499 | 0.01 |
| 24500 | **0** | 0.4552 | 1.000 / 0.545 | 0.003 |

**τ\* 는 N 에 의존한다.** 감시 예산이 작을 때(N ≤ 490)는 껍질 밖(τ\* > 0)이 유리하고, N ≥ 980 부터는 껍질 위(τ\*=0)가 최적이다.

단 N=245 의 τ\*=1e-2 지점에서 고전 AUC 는 **0.663** 으로, Phase 1 의 τ_break=3e-4 를 한참 넘었다 — **이미 사각지대가 아니다.** Δ 이득 0.02 를 위해 은밀성을 버리는 거래이므로, 이를 "운용 권고"로 쓰면 안 된다.

**τ_conv 는 N 이 클수록 작아진다**(0.1 → 0.003). 감시를 많이 할수록 공격자가 껍질에서 조금만 벗어나도 우위가 사라진다.

> ★ τ_conv 판정선 `Δ < 0.05` 는 **사후 정의**다(사전등록 아님). 그렇게 표기했다.

## Phase B 사후 부호검정 (참고용, 사전등록 아님)

사전등록 기준은 **페어드 부트스트랩 CI** 였고 그 판정은 `gate_s7_phase2b.md` 대로 **우위 없음**이다. 아래는 시드별 Δ 부호만 본 사후 검정이며, **판정선 사후 변경 금지** 원칙에 따라 참고 자료로만 남긴다.

| τ | N | Δ>0 시드 | 양측 p | Δ 중앙 | CI 배제 |
|---|---|---|---|---|---|
| 0 | 245 | 4/10 | 0.754 | −0.0017 | 0/10 |
| 0 | 490 | 8/10 | 0.109 | +0.0073 | 2/10 |
| 0 | **980** | **9/10** | **0.022** | +0.0104 | 3/10 |
| 0 | **1960** | **9/10** | **0.022** | +0.0027 | 2/10 |
| 0 | 4900 | 2/10 | 포화 | +0.0000 | 0/10 |
| 0 | 24500 | 0/10 | 포화 | +0.0000 | 0/10 |

N=980·1960 에서 9/10 이 양수(p≈0.022)다. **아주 작은 일관된 효과는 있을 수 있다.** 그러나 (a) 사후 검정이고, (b) 효과 크기가 **+0.010 AUC** 이며, (c) 파라미터 효율이 가장 크게 작용해야 할 **N=245 에서는 4/10 로 부재**하다 — 예측과 반대 방향이다.

이 크기로는 "왜 양자 생성 모델인가" 를 지탱할 수 없다. Phase F 가 교정 예산을 245 까지 낮춰서도 같은 결론을 냈다.
