# Gate S3b — 무신호 사영 대조군: "양자 제약인가, 물리성 제약 일반인가"

- 실행: 2026-07-29 · HEAD `c852052` (= origin/main) · numpy 2.2.6 / scipy 1.15.3 / cvxpy 1.7.5
- 산출: `results2/gate_s3b/s3b.json` (2.8 MB), `s3b_bias_vs_n.png`
- 신규 코드: `tools_s3b/s3b_ns_control.py`. **`tools/` 무수정.**
- 소요: 셀 계산 3478s (60셀 × 300rep, 14워커)

추정기 사다리 — 셋 다 **같은 표본**을 공유하고 **같은 CF-LP** 에 입력한다.

| 칸 | 입력 | 제약 |
|---|---|---|
| plugin | 원시 p̂ | 없음 (12 자유도) |
| **NS 사영** | p̂ → 무신호 폴리토프 최근접점 | 물리성만 (8 자유도) |
| quantum | p̂ → `quantum_behavior` 적합 | 양자집합 (9-파라 과잉매개화, 차원 ≤8) |

0-3의 완전 일치는 NS 사영이 난수를 쓰지 않아 s3의 RNG 스트림을 교란하지 않음을 확증한다.

### PC-1 — **0 포함** (NS 사영이 허위 인증을 해소한다)

헤드라인 셀 (V=0.70, 참 CF=0, n=245, delft):

| 추정기 | mean | bias | MSE | CI95 | **0 포함** |
|---|---|---|---|---|---|
| plugin | 0.147958 | +0.147958 | 2.5091e-02 | [0.05502, 0.27416] | **False** |
| **NS 사영** | 0.040266 | +0.040266 | 5.0578e-03 | [0.00000, 0.19132] | **True** |
| quantum | 0.039391 | +0.039391 | 4.8529e-03 | [0.00000, 0.19112] | True |

**V=0.70 행 전체(n ∈ {100,245,500,1000,5000} × 양 alloc = 10셀)에서 NS 사영 CI 는 전부 0 을
포함하고, plugin CI 는 전부 0 을 배제한다.** 사전등록 판정: *포함 → 허위 인증이 물리성
제약만으로 해소됨 → 양자 특유 아님.*

### PC-2 — 저장 시드는 "유의", 그러나 **시드 불안정**

저장된 결과(시드 SEED+4242):

| | MSE_a → MSE_b | Δ 평균 | CI95 | 유의 |
|---|---|---|---|---|
| Δ₁ = plugin − NS | 2.5091e-02 → 5.0578e-03 | **+2.0020e-02** | [+1.8076e-02, +2.2020e-02] | True |
| Δ₂ = NS − quantum | 5.0578e-03 → 4.8529e-03 | **+2.1377e-04** | [+1.086e-06, +4.453e-04] | True |

**Δ₂ 의 CI 하한이 +1.09e-06 로 0 에 붙어 있어, 부트스트랩 시드 20벌로 재검한 결과:**

```
0 배제 시드 :  3 / 20
CI 하한 분포 :  중앙 −8.36e-06,  범위 [−1.77e-05, +1.10e-06]
```

즉 사전등록한 MSE-부트스트랩 기준은 **이 셀에서 안정된 답을 주지 않는다.** 저장값이
"유의"로 나온 것은 시드 추첨의 결과다. (판정선을 바꾸지 않았다 — 기준을 그대로 적용한
결과가 시드에 의존한다는 사실을 보고한다.)

### 효과크기 — NS 가 98.94%, 양자 증분 1.06%

```
MSE  plugin 2.5091e-02  →  NS 5.0578e-03  →  quantum 4.8529e-03
Δ₁ = +2.0020e-02   (총 감소분의 98.94%)
Δ₂ = +2.1377e-04   (총 감소분의  1.06%)
```

### 부호검정 — 방향은 실재, 크기는 무시할 수준

페어드 제곱오차 비교(분포무관, 300 rep):

```
quantum 이 더 좋음 : 130 rep
NS 가 더 좋음      :  19 rep
정확히 동일        : 151 rep  (|차| < 1e-12, 50.3%)
```

동점이 아닌 149 rep 중 130 이 quantum 우세로 **방향은 일관**된다. 그러나 그 우위가 만드는
MSE 차는 총 감소분의 1.06% 다. 절반이 넘는 rep 에서 양자 적합이 NS 사영과 **정확히 같은
행동**을 낸다.

### PC-3 — 예측 적중

|bias| : plugin 0.147958 > NS 0.040266 > quantum 0.039391. 예측 순서 `plugin > NS > quantum` 성립.
(n=100 에서는 quantum 0.0602 < NS 0.0676 로 격차가 더 크고, n ≥ 500 에서는 소수 4자리까지 동일.)

### ★ B-5 — 경계 수축 병리는 **양자 제약에만** 있다

V=1.00 (치렐손, 참 CF = 0.414214), n=245:

| 추정기 | bias (uniform) | 참값 포함 | bias (delft) | 참값 포함 |
|---|---|---|---|---|
| plugin | +0.002185 | True | +0.008585 | True |
| **NS 사영** | **−0.000820** | **True** | **+0.005538** | **True** |
| quantum | **−0.068936** | **False** | **−0.070128** | **False** |

**양자 추정기는 치렐손 경계에서 편향 −0.070 이고 CI 가 참값을 배제한다. NS 사영은 그 병리를
갖지 않는다.** 양자 제약의 대가가 격리됐다 — 이것이 이 실험의 가장 깨끗한 결과다.

## [탐색의 한계]

- **Phase C(NPA 사영) 미실시** → **앤자츠(9파라)와 양자집합을 분리하지 않았다.** 관측된
  1.06% 증분이 양자집합에서 온 것인지 특정 2큐빗 매개화에서 온 것인지 미분리다.
- **Δ₂ 판정의 기준 자체가 부적합하다.** MSE 부트스트랩은 소수의 큰 오차 rep 이 지배해 CI 가
  불안정하다. 이 크기의 효과를 판정하려면 부호검정·순위검정 같은 분포무관 통계나 더 큰
  reps 가 필요하다. 사전등록 시 이를 예상하지 못했다.
- (2,2,2) 한정 · Werner 가정 · CANON 각도 한정.
- 양자 추정기는 **참값이 양자집합 안에 있을 때만** 정당하다. B-5 의 병리는 참값이 경계에
  있을 때 이 전제가 어떻게 실패하는지 보여준다.
- NS 사영은 폴리토프로의 사영(QP)이고 양자집합은 곡면이라 **두 제약의 기하가 다르다.**
  같은 "사영"이라는 말로 묶여 있으나 계산 성격이 다르다.
- CF-LP 는 신호가 있는 입력에도 형식적으로 돌지만, 그 값의 해석이 정당한 것은 plugin 칸뿐이다.
- V=0.70 이외 행에서는 참 CF>0 이라 "허위 인증" 개념이 적용되지 않는다. PC-1 은 V=0.70 전용.

## [미검증·추정]

- **151/300 rep 에서 양자 적합과 NS 사영이 정확히 일치하는 이유**: 표본의 NS 사영이 이미
  양자집합 안에 들어가 적합이 그 점을 그대로 회수한 것으로 **추정**되나 검증하지 않았다.
  (확인하려면 사영점의 NPA 소속 여부를 판정해야 한다 — s8 의 SDP 를 재사용하면 가능하다.)
- **Δ₂ 의 부호가 다른 셀·다른 시드에서 유지되는지**: 헤드라인 셀에서만 20벌 재검했다.
  나머지 59셀은 저장 시드 1벌뿐이다.
- **B-5 병리의 일반성**: V=1.00 두 alloc 에서만 관측했다. V=0.96 등 경계 근방 다른 점은
  격자에 없다.
- **s3 의 결론을 어디까지 다시 써야 하는가**: 본 실험은 "plugin 이 허위 인증한다"는 s3 의
  실용적 결론을 **바꾸지 않는다**(plugin CI 는 전 n 에서 0 배제). 바뀌는 것은 **원인 귀속**이다 —
  억제의 98.94% 는 물리성 제약에서 오고 양자 제약의 증분은 1.06% 이며 그 통계적 유의성조차
  시드 불안정하다. 논문에서 이 대목을 "양자 사영 추정기의 이점"으로 서술했다면
  **"물리성(무신호) 제약의 이점이며, 양자 제약은 측정 가능한 증분을 주지 않는 대신
  치렐손 경계에서 편향을 만든다"** 로 고쳐야 한다. 이 재서술의 최종 문안은 미확정이다.
