## 3. 폐기된 중복 작업 (참고용 기록)

이 세션은 위 사실을 모른 채 `gate-s5-c2-unmonitored-shell` 브랜치에서 (2,3,2) 미감시 껍질 실험을 사전등록 프로토콜로 재실행했다. **원격·로컬 브랜치 모두 삭제됨.** 기록 목적으로만 남긴다:

- 독립 방법(닫힌형 라그랑주 정상조건 `u=(uₙ−μu_c+2νs)/(1−μ)`, μ=2.042642, ν=−0.319201)으로 V=0.856에서 **max KL = 0.0104619 (τ=0, 껍질 밀착)** 를 얻었다. 원격의 등식제약 SLSQP 값 **0.010182**와 정합(제약 처리 방식 차이: `≤ r+τ` 부등식 vs `= NCfloor` 등식).
- 즉 **원격 결과가 독립 재현되었다**는 부수적 확인은 성립한다. 그러나 낡은 `gate_s5_multifacet.py`(408줄 확장 전) 기준이라 산출물 자체는 채택하지 않는다.
- 그 과정에서 범용 최적화기가 3회 "해 없음"처럼 실패했다(penalty 202 재시작 가능해 0개 / 목적 뒤집기 / fsolve 크래시). **전부 최적화 실패이지 공집합 증거가 아니었다.** 문제 구조를 쓴 방법(닫힌형·중첩 이분법·SLSQP 명시제약)으로 바꾸니 즉시 풀렸다. 이 교훈은 원격 로그의 "벌점 Powell → 등식제약 SLSQP 교체" 기록과 **동일한 함정**이다.

## 4. 다른 에이전트를 위한 체크리스트

1. **`git fetch origin` 먼저.** "없다"는 단정은 fetch 후에만. `git branch -vv`의 동기 표시를 믿지 말 것(stale 가능).
2. **권위 있는 출처는 `results2/*/**.json`의 저장값**이다. 로그(.md)의 수치는 대체로 정확하나 반올림·기준 차이가 있다(§2-4 사례).
3. **κ·마진 법칙 인용 시 "Tsirelson 경계 제외" 명시 필수.** 전 구간에서는 κ가 상수가 아니다(`kappa_constant: false`).
4. **"A₂만 건드리는 공격" 금지.** 미감시 비중 64.3%이지 100%가 아니다. A₂ 1D 스캔은 음성이다.
5. **R6 유지**: (2,2,2) 탐지 커버리지 불가능성 정리는 그대로다. (2,3,2)의 M>0은 **기하가 다른 시나리오**의 결과이지 그 정리의 반증이 아니다.
6. **AUC는 상한**이다(양자 템플릿에 모집단 참값을 그대로 씀, 훈련잡음 0). 최강 공격점 하나의 값이며 클래스 커버는 E3 붕괴곡선 담당.
7. **모델클래스 분리이지 quantum supremacy 아님. 키 보안이 아니라 장비 무결성 맥락.**
