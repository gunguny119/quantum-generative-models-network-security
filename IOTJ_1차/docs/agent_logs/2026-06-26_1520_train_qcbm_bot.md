- **작성 주체**: 로컬 Claude Code agent (default mode)

## 1. 작업 목적
Bot(복잡·강한 joint 의존·분리가능: marginal AUC 0.287 역방향, emp_joint 0.875, 고랭크 r=7, 점유 8.81%)
데이터로 QCBM(12q, B2 12bit)을 학습해 **QCBM이 marginal(0.287)을 넘어 emp_joint 상한(0.875)에
얼마나 근접하는지** 측정. 핵심 질문: "QCBM이 이 복잡한 joint를 학습으로 잡는가". 판정은 다음 단계.

## 4. 재사용 경로 (코드 확인 완료)
- 인코딩(B2 12bit, Bot 적용): `E.discretize`(SPEC8 proto2+syn1+psh1+size4) + `TB2.iat_to_bits`/`append_bits`
  로 FwdIAT2+FlowIAT2 추가. 경계: size 16버킷 `E.size_edges_from_benign`, IAT log1p 4버킷
  `TB2.log1p_quantile_edges` — **모두 Bot benign train(seed=7,0.7)에서 새로 생성**(HOIC 경계 재사용 안 함).
  (train_qcbm_iat_b2.build_b2는 HOIC 경로/라벨 하드코딩 → 수정 대신 하위 함수 재사용. 이 조합은
   tools/diagnose_attack_complexity.py에서 Bot emp_joint/marginal=0.875/0.287 재현 검증됨.)
- 학습: `E.train_one`(seed별 독립, rng=default_rng(2000+seed), 결정론적, p_final/weights/hist 반환)을
  `multiprocessing.Pool(initializer=E._init)` + **imap_unordered**로 호출 → 완료되는 restart마다 즉시 체크포인트.
  (run_config는 16개를 한 번에 끝내고 중간 저장이 없어 재사용 대신 train_one을 직접 호출.)
- 평가: `TB2.eval_dist`(= `E.anomaly_eval`, s=-log p, attack=positive, raw MWU). 방향반전 없음.

## 5. 체크포인트 / 재개 메커니즘
- 각 restart(seed) 완료 즉시 `results2/bot_ckpt/restart_<seed>.npz`에 원자적 저장
  (tmp 파일 작성 후 os.replace) — p_final, weights, loss_hist, gnorm_hist, final_mmd2, tv, kl, **AUC**, youden, logp_gap.
- `imap_unordered`로 완료되는 즉시 저장 → 와이파이/덮기/종료로 중단돼도 **이미 끝난 restart는 디스크에 보존**.
- 스크립트 시작 시 `bot_ckpt/`를 스캔 → 완료 seed 집합 구성 → **남은 seed만** 학습 제출(처음부터 다시 안 함).
- EPOCHS 결정은 `bot_ckpt/decision.json`에 1회 저장 → 재개 시 동일 EPOCHS 사용(일관성).
- 한 번의 병렬로 16개를 중간저장 없이 끝내지 않음(NWORKERS=4 동시, 완료마다 저장).

## 8. 학습 결과
- 점유 361/4096(8.81%), params=216(L=6×12×3), EPOCHS=300, 16 restart 전부 완료.
- best(최소 MMD²) = **seed 7**: MMD²=**5.58e-3**, TV=**0.4933**, gradient 6.02e-3→3.43e-4(**바렌플래토 없음**).
- 학습곡선(`train_qcbm_bot.png`): best는 300ep까지 MMD² 계속 하강(특히 ~240ep 추가 하강), restart 간 편차 큼
  (고랭크·조밀 분포라 국소최적 다양 — 일부는 ~1e-2에서 정체). gradient는 1e-4~1e-2 유지(소실 아님).

## 9. 핵심 비교표 (AUC, s=-log p, attack=positive, raw MWU)
| 모델 | AUC | 비고 |
|------|-----|------|
| marginal (독립곱) | 0.2870 | 역방향(0.5 미만) |
| **QCBM (12q, Bot, best=seed7)** | **0.7458** | 16 restart 중 최소 MMD² |
| emp_joint | 0.8749 | 상한 |
- **상한 근접도**: best 0.7458 / 0.8749 = **85.2%**.
- **best − marginal = +0.4588**. marginal 초과 restart = **16/16**. emp_joint 초과 restart = **0/16**(상한이므로 정상).
- 16 AUC 분포: min **0.5235** / median **0.6650** / max **0.8167** / std **0.0709**.
- 정렬: 0.523, 0.594, 0.604, 0.613, 0.614, 0.620, 0.635, 0.656, 0.674, 0.677, 0.706, 0.721, 0.726, 0.736, **0.746(best-MMD²)**, **0.817(max-AUC)**.
- 정합 재계산: emp_joint=0.8749 / marginal=0.2870 (기준과 일치, §4 게이트 통과).

## 10. 사실 관찰 (판정 아님)
1. **QCBM은 marginal(0.287)을 크게 넘는다 — 16/16 전부.** best +0.459, 최저 restart도 0.524>0.287.
   → "독립곱으로는 역방향이던" Bot을 QCBM이 joint 학습으로 분리 방향을 잡아냄.
2. **emp_joint 상한(0.875)엔 부분 도달(best 85.2%).** 단일 모델로 상한을 넘진 못함(0/16).
   best-MMD² 모델 AUC 0.746, 별도로 max-AUC restart는 0.817(상한의 93%).
3. **restart 편차 큼(std 0.071, 0.52~0.82)** + best TV 0.49(상당한 잔차). 216 params로 고랭크·조밀
   Bot 분포를 "부분적으로" 포착(완전 포착 아님). 바렌플래토는 없음(gradient 건강).
4. 즉 사실: **복잡한 joint(marginal로 안 풀리던)를 QCBM이 학습으로 상당 부분 잡았으나, 4096상태
   고랭크 분포를 216 params로 상한까지 채우진 못함.** (HOIC 단순 분포에서 best가 상한 99% 근접했던 것과 대조 — 다음 단계 효율비교 대상.)
