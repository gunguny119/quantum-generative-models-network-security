## 1. 작업 목적

B1(10bit, +FwdIAT)에서 QCBM 0.8811 > marginal 0.8726, emp_joint 상한 99.5% 실현됨. B2는 emp_joint 상한 joint 이득이 훨씬 큼(**+0.052** vs B1 +0.013).
가설: **joint 이득이 클수록 QCBM이 marginal을 더 큰 폭으로 이긴다(단조 관계).**
핵심 질문: QCBM AUC가 B2 marginal(~0.874)을 넘고 B1보다 큰 폭인가? emp_joint 상한(~0.926) 근접도? 점유 2.3% 희소성 영향?
- 인코딩: B2 = proto2+syn1+psh1+size4 + Fwd IAT(2bit) + Flow IAT(2bit) = **12bit, 4096상태**. 대상=HOIC.

## 4. B2 인코딩 상세

- 비트 패킹(MSB→LSB): `state = (((8bit_base << 2) | FwdIAT) << 2) | FlowIAT` = 12bit, 4096상태.
  - 8bit base = proto2 syn1 psh1 size4 (`E.discretize`).
- IAT 컬럼: **Fwd IAT Mean, Flow IAT Mean**. log1p 후 benign train 분위수 4버킷:
  - Fwd IAT inner edges = `[5.739, 5.9067, 7.8581]`
  - Flow IAT inner edges = `[5.3351, 5.5026, 7.4548]`
- **benign train 점유 = 94/4096 (2.3%)** — 매우 희소(B1은 7.7%). 희소성이 학습/상한 실현을 제약할 가능성 모니터링.

## 5. smoke 시간 + 본 학습 설정

- smoke (RESTARTS=1, EPOCHS=50, L=6): **wall=112.9s → 2.26s/epoch** (B1의 1.47s보다 무거움 — 4096상태/12큐빗).
- **smoke TV=0.599** (B1 smoke 0.13 대비 나쁨) → 희소+고차원이라 분포 학습이 더 어려움 시사. 본 학습(300ep×16)에서 개선 여부가 관건.
- 추정: **est_300 ≈ 678s (~11분)** → 규칙상 ≤3h → **확정: RESTARTS=16, EPOCHS=300, L=6, LR=0.1**. (5h 예산 여유.)
